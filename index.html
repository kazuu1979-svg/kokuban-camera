事務所へ送る

写真を1つのファイル（zip）にまとめて LINE で送ります。写真の画質が落ちず、撮った日と工種・測点・工程の名前が付いたまま届くので、事務所のパソコンで現場の写真フォルダへ自動で並べられます。

送る写真

LINE が出てこない時・パソコンでの受け取り方
  1. 「送る」で出た画面に LINE が無い時は「ファイルに保存」を押し、LINE のトークで ＋ → ファイル → 保存したファイルを選んで送ってください。
  2. 事務所のパソコンでは、LINE のトークのファイルを 右クリック → 名前を付けて保存 で 00_受信箱 に保存します。朝のまとめが現場の 写真\黒板カメラ\ に工種ごとに並べます。
  3. LINE のファイルは保存期間があります。届いたら早めにパソコンへ保存してください。
LINE のアルバムに入れる

ページから LINE のアルバムを直接作ることはできません（LINE がその仕組みを外に出していないため）。かわりに、下の2つを押してから LINE で作ります。送る写真は上の「送る写真」で選んだ物です。

  1. LINE でグループのトークを開き、右上の ≡ → アルバム → 右下の ＋（アルバムを作成）。
  2. 写真を選ぶ画面で、①で保存した写真（いちばん新しい所に並んでいます）を選んで 次へ。
  3. アルバム名の所を長押しして ペースト（②でコピーした名前）→ 作成。グループのみんなが見られます。

使い方

撮る

  1. はじめの画面で 工事名 を選ぶ（または入れる）。
  2. カメラを開く。最初だけ「カメラを使ってよいか」と聞かれるので 許可 を押す。
  3. 下の 工種・測点 の行を押して選ぶ。工程 は ◀ ▶ で変える。
  4. 工種 の ◀ ▶：前・次の工種に変わる（工程は「施工前」に戻る）。
  5. 測点 の ◀ ▶：番号を振る工種（下地補修など）は番号が1つずつ（N-1-2 → N-2-2）、ほかの工種は階が1つずつ（2階 → 3階）変わる。どちらが変わるかは「測点」の横に出る。
  6. 白い丸（シャッター）で撮る。撮ると工程が1つ進むので、続けて撮れる。
  7. 黒板は指で動かせる。黒板の上を2本指で広げると黒板が大きくなる。黒板の外を2本指で広げるとカメラが拡大する。

撮った後

  1. 左下の小さい写真か、はじめの画面の写真を押すと、1枚ずつ見られる（左右で前後の写真）。
  2. LINEへ送る：出てきた画面で LINE → グループを選んで送信。
  3. 丸・矢印・字を書く：指摘の所に赤い丸や矢印を書ける。書く前の写真も残るので、あとで書き直せる。
  4. 黒板を直す：選び間違えた時。撮った日時はそのまま。
  5. 備考：事務所へ送るファイルの一覧と工事写真帳に出る（黒板には出ない）。

事務所へ送る（まとめて）

  1. はじめの画面の 事務所へ送る を押す（選んだ写真だけなら「選ぶ」→ 事務所へまとめて送る）。
  2. 送る写真（まだ送っていない・今日・全部）を選んで ファイルを作る。
  3. 送る → LINE → 送り先を選んで送信。写真が多い時は「その1・その2」に分かれるので、全部送る。
  4. 事務所のパソコンで 00_受信箱 に保存すると、現場の写真フォルダへ自動で並びます。
  5. LINE のアルバム：同じ画面の「① 携帯に保存」「② 名前をコピー」を押してから、LINE のグループ → ≡ → アルバム → ＋ で作る。

工事に合わせる・職人さんに渡す

  1. 工種・部位：この工事だけの工種・工程・部位を足す・消す・並べ替える。
  2. 職人さんに渡す：同じ設定を1本のリンクにして LINE で送る。

気をつけること

  1. 写真はこのスマホの中に残ります。スマホを替える・ブラウザの「履歴とデータを消す」をすると消えます。大事な写真は LINE へ送る・携帯に保存しておいてください。
  2. ホーム画面に置くと使いやすくなります（Safari の共有ボタン → 「ホーム画面に追加」）。
  3. iPhone は、ホーム画面の黒板カメラと Safari の黒板カメラで写真が別々に残ります。
